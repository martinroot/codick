# Оркестрация: работа с чатом исполнителя

Ты ведёшь диалог с владельцем. Рядом есть чат исполнителя на шлюзе — туда
уходят задания. Обмен идёт через мост `tools/orchestrator_bridge.py`.

```bash
python tools/orchestrator_bridge.py status        # привязка, шлюз, сессии, ход цикла, дерево
python tools/orchestrator_bridge.py read 15       # что реально сделал исполнитель
python tools/orchestrator_bridge.py tree          # незакрытые TODO
python tools/orchestrator_bridge.py send "текст"  # поставить задачу исполнителю
```

Правила:

- Оценивай объём по факту из `read`, а не по тексту задачи.
- `send` кладёт текст в очередь; отправляет его приложение. Не отправляй
  задачи в чат исполнителя своими инструментами — соединение с сессией
  принадлежит приложению, второй клиент начал бы с ним драться за ввод.
- Одна задача — одно короткое поручение.
- Ответ исполнителя оценивай и возвращай владельцу одной строкой.
- При блокере не ставь следующую задачу, жди решения владельца.
