# Проверка HermesWorkspace 1.2

.NET SDK 8.0.425. WPF-проект собран, опубликован win-x64 self-contained single-file. Сборка без предупреждений и ошибок. Совместимые ProfileLogicTests с WPF скомпилированы, но их Windows-зависимые проверки в Linux не запускались.

## Выполнено

- 63 проверки реального WorkspaceCoordinator, WorkspaceChatRelay, TuiGateway, TuiCompletionSignal и AgentPackages. Тестовые Store/дерево в этом наборе не заменяют проверку настоящего файла дерева.
- Проверены: выбранные существующие чаты и их идентичность, отказ при неверном/общем маршруте, последовательное выполнение после next_id, STOP во время поручения, локеры между разными шлюзами, ожидание владельца, повторная оценка без повторного выполнения, три неудачных приёмки, читаемое представление JSON, терминальные события ошибок/отмены.
- Проверка настоящего TuiGateway на локальном HTTP/WebSocket mock-сервере: resume выбранной stored-сессии, prompt.submit обычного сообщения, финальный ответ; обрыв сокета завершает ожидающий запрос ошибкой и не создаёт ложный результат.
- 6 проверок настоящего TreeBriefs на файле: чтение вложенного дерева, rewrite и перечитывание очереди, сохранение внешних метаданных, отсутствие частичной записи невалидного пакета правок, удаление принятого TODO из очереди, backup.
- 4 Python-проверки install_agent.py: no-execution/no-secret default, сохранение env и backup, отказ при symlink-перенаправлении записи, отказ при пересечении исходной и целевой папки.

Всего 73 выполненные проверки. Mock-сервер не подтверждает особенности версии Hermes на сервере пользователя.

## Первый живой прогон на Windows

1. Сохранить прежнюю папку приложения; запускать новый Windows/HermesWorkspace.exe, сохраняя AppData.
2. Spy AI → Настройки: назначить шлюз, существующий чат оркестратора и существующий чат исполнителя.
3. Обновить старый orchestration skill, если в нём фигурирует gateway_chat.py; текст tools/skill-short.md.
4. Обсудить цель/бюджет, запустить START на небольшой проверяемой задаче.
5. Убедиться, что поручение и финальный ответ появились в выбранном чате исполнителя; проверка — в выбранном чате оркестратора; принятый TODO закрыт и следующий планируется без нового аппрува.
6. Ответить на запрос разрешения/уточнения исполнителя в его чате. Проверить owner pause и продолжение через ответ «блокер снят, продолжай».
7. Запустить другой проект на другом шлюзе; одинаковый @lock:ресурс должен сериализовать работу. STOP должен прекратить локальный цикл. Закрыть/открыть приложение: незавершённые итерации требуют проверки.

Native WPF UI и реальные AI Spy/Hermes-сервера здесь не запускались. Приложение не работает после закрытия. STOP не гарантирует остановку уже запущенных серверных процессов. Денежные ограничения платных действий задаются в контексте; жёсткого общего лимита списаний в долларах эта сборка не добавляет. Цена модели берётся только из отчёта шлюза. Удалённое дерево/CRM автоматически не меняется.
